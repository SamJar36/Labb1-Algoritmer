# Algorithms

This is my first school project, in which I was to design a simple console application with a specific algorithm. The program asks for a user input string, and then searches for all substrings that have numbers starting and ending with the same digit, without the start/end digit or any other character than digits appearing in between. Then it calculates the total amount and returns a value.
